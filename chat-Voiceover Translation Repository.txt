## 1. Project Overview

### 1.1 Purpose
Upgrade the existing "Voiceover-Translation" (Recap → Myanmar) Windows desktop application with new features that improve usability, video editing capabilities, voice quality, and workflow efficiency. The application translates narrated recap videos from any language into Myanmar (Burmese) with synchronized voiceover.

### 1.2 Goals
- Reduce repetitive user actions through templates and presets
- Add professional video editing capabilities (crop, overlays, color correction)
- Improve Myanmar voice quality without requiring paid API access
- Simplify the user interface for non-technical users
- Maintain backward compatibility with existing job folders and checkpoints

### 1.3 Constraints
- Must run on Windows 10/11 with Python 3.12
- Must use FFmpeg for all video processing
- GUI must remain Tkinter-based (no framework migration)
- All new features must be checkpoint-resumable
- Must not break existing Smart Sync timing logic
- Free/local solutions preferred over paid APIs

## 4. Feature 2: Custom Image Overlay

### 4.1 Description
Allow users to add one or more PNG/JPG images as overlays on the video. Each image can be positioned anywhere on screen via drag-and-drop on the preview canvas, resized, and given opacity.

### 4.2 Functional Requirements

| ID | Requirement |
|----|-------------|
| IO-01 | User can add up to 5 custom image overlays |
| IO-02 | Each overlay supports PNG (with transparency) and JPG |
| IO-03 | User can position overlay by dragging on preview canvas |
| IO-04 | User can resize overlay via slider (percentage of video width) |
| IO-05 | User can set overlay opacity (10% to 100%) |
| IO-06 | User can remove an overlay |
| IO-07 | Overlay positions are stored as percentages (resolution-independent) |
| IO-08 | Overlays are rendered AFTER crop but BEFORE subtitles |
| IO-09 | Overlays persist in presets and job configs |

### 4.3 Data Schema

Stored in settings under `"custom_overlays"`:

```json
"custom_overlays": [
  {
    "id": 1,
    "path": "C:/Users/user/images/watermark.png",
    "x_percent": 0.85,
    "y_percent": 0.05,
    "width_percent": 0.12,
    "opacity": 0.9,
    "enabled": true
  },
  {
    "id": 2,
    "path": "C:/Users/user/images/qrcode.png",
    "x_percent": 0.05,
    "y_percent": 0.80,
    "width_percent": 0.15,
    "opacity": 1.0,
    "enabled": true
```

**Coordinate system:**
- `x_percent`: 0.0 = left edge, 1.0 = right edge (position of image's LEFT edge)
- `y_percent`: 0.0 = top edge, 1.0 = bottom edge (position of image's TOP edge)
- `width_percent`: fraction of video width (height auto-calculated from aspect ratio)

### 4.5 FFmpeg Implementation

**In `text_overlay_service.py` or `core.py`:**

For each overlay, add an input and filter:

```python
def build_overlay_filters(base_video: str, overlays: list[dict], video_w: int, video_h: int) -> tuple[str, list[str]]:
    """
    Returns (filter_complex_string, list_of_input_files)
    """
    inputs = []
    filter_parts = []
    current_stream = base_video  # e.g., "[0:v]" or "[cropped]"

    for i, ov in enumerate(overlays):
        if not ov.get("enabled", True):
            continue
        input_index = len(inputs) + 1  # +1 because input 0 is the video
        inputs.append(ov["path"])

        # Calculate pixel positions
        x_px = int(ov["x_percent"] * video_w)
        y_px = int(ov["y_percent"] * video_h)
        w_px = int(ov["width_percent"] * video_w)

        # Scale the overlay image
        filter_parts.append(
            f"[{input_index}:v]scale={w_px}:-1,format=rgba,"
            f"colorchannelmixer=aa={ov['opacity']:.2f}[ov{i}]"
        )

        # Overlay onto current stream
        out_label = f"[ovout{i}]"
        filter_parts.append(
            f"{current_stream}[ov{i}]overlay=x={x_px}:y={y_px}{out_label}"
        )
        current_stream = out_label

    return current_stream, inputs
```

### 4.6 Edge Cases
- Image file missing at render time → skip overlay, log warning
- Image extends beyond video boundary → clamp position to keep image visible
- Very large image → auto-scale down to `width_percent` before overlay
- Non-PNG without transparency → works fine, just no transparent areas
- Corrupted image file → skip with error log, do not crash render

### 5.1 Description

### 5.2 Functional Requirements


### 5.4 Auto-Crop Implementation

**New file:** `app/crop_detect.py`

```python
import subprocess
import re
from pathlib import Path

def detect_black_bars(
    ffprobe_path: str,
    ffmpeg_path: str,
    video_path: str,
    duration_sample: float = 10.0,
    threshold: int = 24
) -> dict | None:
    """
    Run FFmpeg cropdetect on the video and parse the result.

    Returns:
        {
            "x_percent": float,
            "y_percent": float,
            "width_percent": float,
            "height_percent": float
        }
        or None if detection fails
    """
    # Get video dimensions first
    probe_cmd = [
        ffprobe_path, "-v", "error",
        "-select_streams", "v:0",
        "-show_entries", "stream=width,height",
        "-of", "csv=p=0",
        str(video_path)
    ]
    result = subprocess.run(probe_cmd, capture_output=True, text=True)
    video_w, video_h = map(int, result.stdout.strip().split(","))

    # Run cropdetect
    detect_cmd = [
        ffmpeg_path, "-i", str(video_path),
        "-vf", f"cropdetect={threshold}:16:0",
        "-t", str(duration_sample),
        "-f", "null", "-"
    ]
    result = subprocess.run(detect_cmd, capture_output=True, text=True)

    # Parse output: look for "crop=W:H:X:Y"
    # Take the LAST occurrence (most stable reading)
    matches = re.findall(r"crop=(\d+):(\d+):(\d+):(\d+)", result.stderr)
    if not matches:
        return None

    # Use median of all detected values for stability
    import statistics
    crops = [(int(w), int(h), int(x), int(y)) for w, h, x, y in matches]
    med_w = int(statistics.median([c[0] for c in crops]))
    med_h = int(statistics.median([c[1] for c in crops]))
    med_x = int(statistics.median([c[2] for c in crops]))
    med_y = int(statistics.median([c[3] for c in crops]))

    # Convert to percentages
    return {
        "x_percent": med_x / video_w,
        "y_percent": med_y / video_h,
        "width_percent": med_w / video_w,
        "height_percent": med_h / video_h
    }
```

### 5.6 FFmpeg Crop Filter Generation

```python
def build_crop_filter(crop: dict, video_w: int, video_h: int) -> str | None:
    """Returns FFmpeg crop filter string or None if crop is disabled."""
    if not crop.get("enabled", False):
        return None

    x_px = int(crop["x_percent"] * video_w)
    y_px = int(crop["y_percent"] * video_h)
    w_px = int(crop["width_percent"] * video_w)
    h_px = int(crop["height_percent"] * video_h)

    # Ensure even dimensions (required by many codecs)
    w_px = w_px - (w_px % 2)
    h_px = h_px - (h_px % 2)
    x_px = x_px - (x_px % 2)
    y_px = y_px - (y_py % 2)

    if w_px >= video_w and h_px >= video_h:
        return None  # No actual cropping needed

    return f"crop={w_px}:{h_px}:{x_px}:{y_px}"
```

### 5.7 Edge Cases
- Crop results in zero-width or zero-height → disable crop, show error
- Crop dimensions not even → round down to nearest even number (codec requirement)
- Auto-detect finds no black bars (crop = full frame) → show "No black bars detected" message
- Crop + output_ratio conflict → crop is applied first, then output_ratio handles remaining aspect difference

### 6.3 Data Schema

```json
  "brightness": 0.06,
  "contrast": 1.1,
  "saturation": 1.3

```

### 6.4 FFmpeg Implementation

Uses the `eq` (equalize) filter:

```python
def build_color_filter(cc: dict) -> str | None:
    if not cc.get("enabled", False):
        return None
    b = cc.get("brightness", 0.0)
    c = cc.get("contrast", 1.0)
    s = cc.get("saturation", 1.0)

    # Skip if all defaults
    if b == 0.0 and c == 1.0 and s == 1.0:
        return None

    return f"eq=brightness={b:.3f}:contrast={c:.3f}:saturation={s:.3f}"
```

### 7.3 Engine Architecture

**New file:** `app/tts_engine.py`

```python
from abc import ABC, abstractmethod
from pathlib import Path

class TTSEngineBase(ABC):
    """Base class for all TTS engines."""

    @abstractmethod
    def generate(self, text: str, voice: str, output_path: Path, **kwargs) -> Path:
        """Generate audio file, return path to WAV/MP3."""
        ...

    @abstractmethod
    def get_voices(self) -> list[dict]:
        """Return list of available voices."""
        ...

    @abstractmethod
    def is_available(self) -> bool:
        """Check if engine is ready to use."""
        ...

    def preview(self, text: str, voice: str) -> Path:
        """Generate a short preview clip."""
        ...


class EdgeTTSEngineAdapter(TTSEngineBase):
    """Wraps existing EdgeTTSEngine from core.py"""
    ...

class MMSMyanmarEngine(TTSEngineBase):
    """Meta MMS TTS for Myanmar (facebook/mms-tts-mya)"""
    def __init__(self, model_path: str = "facebook/mms-tts-mya"):
        self.model = None
        self.tokenizer = None

    def is_available(self) -> bool:
        try:
            import transformers
            return True
        except ImportError:
            return False

    def generate(self, text: str, voice: str, output_path: Path, **kwargs) -> Path:
        import torch
        import scipy.io.wavfile
        inputs = self.tokenizer(text, return_tensors="pt")
        with torch.no_grad():
            output = self.model(**inputs).waveform
        scipy.io.wavfile.write(
            str(output_path),
            rate=self.model.config.sampling_rate,
            data=output.numpy().squeeze()
        )
        return output_path


class PiperTTSEngine(TTSEngineBase):
    """Piper TTS - fast local inference."""
    ...

class ElevenLabsEngine(TTSEngineBase):
    """ElevenLabs API with free tier support."""
    ...
```

```python
def _wrap_ssml(self, text: str, rate: str, pitch: str, pauses: bool = True) -> str:
    """Wrap text in SSML for more natural speech."""
    # Add pauses at sentence boundaries
    if pauses:
        text = text.replace("။", '။ <break time="400ms"/>')
        text = text.replace("၊", '၊ <break time="200ms"/>')

    return (
        f'<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xml:lang="my-MM">'
        f'<prosody rate="{rate}" pitch="{pitch}">'
        f'{text}'
        f'</prosody>'
        f'</speak>'
    )
```

## 8. Feature 6: Audio Auto-Ducking

### 8.1 Description
Automatically reduce the volume of the original video's background music/sound effects when the Myanmar narrator is speaking, then restore volume during pauses. This creates a professional "radio DJ" effect.

### 8.2 Functional Requirements

| ID | Requirement |
|----|-------------|
| AD-01 | Toggle to enable/disable auto-ducking |
| AD-02 | Slider to set duck volume (how quiet BGM gets: 10% to 80%) |
| AD-03 | Ducking is based on TTS segment timestamps (from smart_sync_plan.json) |
| AD-04 | Smooth fade-in/fade-out (200ms ramp) to avoid abrupt volume jumps |
| AD-05 | Works with both Edge TTS and Gemini TTS timing data |

### 8.3 Implementation Approach

Since we already have exact timestamps for each narration segment from `smart_sync_plan.json`, we can use FFmpeg's `volume` filter with timeline expressions.

**Generate volume expression from segments:**

```python
def build_ducking_filter(segments: list[dict], duck_volume: float, fade_ms: int = 200) -> str:
    """
    Build FFmpeg volume filter expression that ducks original audio
    during narration segments.

    segments: list of {"audio_start": float, "audio_end": float, ...}
    duck_volume: 0.0 to 1.0 (e.g., 0.3 = 30% volume during narration)
    """
    fade_s = fade_ms / 1000.0
    conditions = []

    for seg in segments:
        start = seg["audio_start"]
        end = seg["audio_end"]
        # Between start and end: duck volume
        # With fade ramps at boundaries
        conditions.append(
            f"between(t,{start},{end})"
        )

    if not conditions:
        return None

    # Build expression: if any segment is active, use duck volume, else 1.0
    # FFmpeg volume filter with 'eval=frame' for dynamic changes
    expr = f"if({'|'.join(conditions)},{duck_volume:.2f},1.0)"

    return f"volume='{expr}':eval=frame"
```

## 11. FFmpeg Filter Chain Architecture

### 11.1 Complete Filter Chain Order

All video filters must be applied in this exact order:

```
[Input Video]
    │
    ▼
[1. CROP]           ← Remove unwanted areas, change resolution
    │
    ▼
[2. COLOR]          ← Brightness, contrast, saturation (eq filter)
    │
    ▼
[3. SMART SYNC]     ← Speed adjustment, freeze frames (from core.py)
    │
    ▼
[4. ZOOM/MIRROR]   ← zoom_factor, hflip
    │
    ▼
[5. SCALE]          ← Scale to output resolution
    │
    ▼
[6. RATIO/PAD]     ← output_ratio + frame_fill (blur/pad)
    │
    ▼
[7. OVERLAYS]      ← Custom images, Logo
    │
    ▼
[8. TEXT]          ← Title, Extra Text
    │
    ▼
[9. SUBTITLES]     ← Narration subtitles
    │
    ▼
[Output Video]
```

### 11.2 Filter Chain Builder

**New file:** `app/filter_chain.py`

```python
class FFmpegFilterChain:
    """Builds the complete FFmpeg filter_complex string."""

    def __init__(self, video_w: int, video_h: int):
        self.video_w = video_w
        self.video_h = video_h
        self.filters: list[str] = []
        self.inputs: list[str] = []  # additional input files (images)

    def add_crop(self, crop: dict) -> None:
        """Step 1: Crop"""
        f = build_crop_filter(crop, self.video_w, self.video_h)
        if f:
            self.filters.append(f)
            # Update dimensions after crop
            self.video_w = int(crop["width_percent"] * self.video_w)
            self.video_h = int(crop["height_percent"] * self.video_h)

    def add_color(self, cc: dict) -> None:
        """Step 2: Color correction"""
        f = build_color_filter(cc)
        if f:
            self.filters.append(f)

    def add_zoom_mirror(self, zoom: float, mirror: bool) -> None:
        """Step 4: Zoom and mirror"""
        if mirror:
            self.filters.append("hflip")
        if zoom > 1.0:
            # Crop-zoom: scale up then crop center
            zw = int(self.video_w * zoom)
            zh = int(self.video_h * zoom)
            self.filters.append(f"scale={zw}:{zh}")
            x_off = (zw - self.video_w) // 2
            y_off = (zh - self.video_h) // 2
            self.filters.append(f"crop={self.video_w}:{self.video_h}:{x_off}:{y_off}")
```
